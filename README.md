# Livraria Gestor Web

Projeto Integrador do curso Técnico em Desenvolvimento de Sistemas — Senac EAD.

## Sobre o projeto

Aplicação web para gerenciamento de uma livraria, desenvolvida como continuação do projeto Livraria Gestor.

## Tecnologias utilizadas

- Java 21
- Spring Boot
- Maven
- MySQL
- HTML, CSS e JavaScript

## Funcionalidades

- Cadastro, consulta, edição e exclusão de livros.
- Cadastro e gerenciamento de clientes.
- Gerenciamento de usuários.
- Registro e consulta de vendas.
- Consulta do histórico de operações.
- Relatórios de vendas por período, livros mais vendidos e desempenho de vendas.

## Banco de dados

O projeto utiliza o MySQL. Antes de executar a aplicação, configure o acesso ao banco de dados nas configurações do projeto.

**Importante:** não publique senhas ou outras credenciais no repositório.

## Como executar

1. Instale o JDK 21, o Maven (ou utilize o Maven Wrapper, caso disponível) e o MySQL.
2. Configure a conexão com o banco de dados.
3. Abra o projeto em uma IDE compatível, como o NetBeans.
4. Execute a aplicação Spring Boot.
